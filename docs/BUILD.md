# دليل البناء — قواعد ملزِمة لكلّ مَن يكتب في هذا المشروع

> المرجع الأوحد للسلوك والقواعد هو **`دستور اساسي.md`** في جذر الريبو.
> هذا الملفّ يشرح **كيف** نكتب، لا **ماذا** نبني.

## 0) الستاك
PHP 8.4 · **Laravel 13** · Blade · Tailwind 4 (Vite) · JS خام (بلا أطر ثقيلة) · SQLite للتطوير.

## 1) ملكيّة الملفّات — قاعدة صارمة لمنع التصادم
كلّ مجال يملك **مجلّداته فقط**:

| المجال يملك | لا يملك |
|---|---|
| `routes/parts/<area>.php` | `routes/web.php` |
| `app/Http/Controllers/<Area>/**` | `bootstrap/**` · `config/**` |
| `app/Services/<Area>/**` | `resources/views/layouts/**` |
| `resources/views/<area>/**` | `resources/views/partials/**` |
| `tests/Feature/<Area>/**` | `resources/views/components/**` (المشتركة) |
| `database/seeders/<Area>DemoSeeder.php` | `database/migrations/**` |
| `app/Models/**` (إضافة علاقات فقط) | حذف/تعديل أعمدة الجداول |

- **ممنوع تعديل ملفّ يملكه غيرك.** لو احتجت مكوّنًا مشتركًا جديدًا، اعمله داخل مجلّدك باسم مُنَطَّق (`resources/views/<area>/components/…`).
- **ممنوع تعديل المايجريشنز القائمة.** المخطّط كامل (138 جدولًا). لو نقصك عمود، أضِف **مايجريشن جديدًا** باسم `2026_08_03_XXXXXX_<area>_<وصف>.php` ولا تلمس القديم.
- `routes/web.php` يحمّل `routes/parts/*.php` تلقائيًّا — أنشئ ملفّك وخلاص.

## 2) الصلاحيّات (12.2.1) — إلزاميّة على كلّ مسار
```php
Route::middleware(['auth', 'permission:courses.view'])->group(...);
```
- في Blade: `@can('tasks.approve', $task)` — البوّابة موصولة بمحرّكنا.
- **العنصر الذي لا يملكه المستخدم يُخفى ولا يُعطَّل** (2.15-أ-7).
- `@owner` للمجموعة المحميّة · `@volunteer` لطبقة التطوّع · `@scope('ENTITY','tasks.edit')`.
- لبناء الاستعلامات: `$user->widestScope('tasks.view')` ثمّ فلترة حسبه.

## 3) الإعدادات (2.13) — ممنوع أيّ رقم أو نصّ محروق
```php
setting('rep.objection.window_days', 5);   // لا تكتب 5 في الكود
rep_rule('meeting.within_3h');             // قيم Rep من جدولها
```
لو ميزتك تحتاج إعدادًا غير موجود، أضِفه في **سيدر مجالك** بنفس نمط المفتاح `المجال.الميزة.المفتاح` مع `default_value`.

## 4) الواجهة — القواعد غير القابلة للتفاوض
- **البساطة أوّلًا (2.15):** سؤال واحد لكلّ شاشة · **فعل رئيسيّ واحد** والباقي في «⋯» · **4 كروت KPI بحدّ أقصى** · **3 فلاتر ظاهرة** والباقي مطويّ · **جدول 5–7 أعمدة** · التفاصيل في بانل/بوب-أب لا صفحة جديدة · **الحالة الفارغة سطر واحد + زرّ واحد** · تحميل كسول للتابات · المدى الافتراضيّ آخر 30 يومًا.
- **الموبايل شرط قبول:** تابات كرقائق أفقيّة · العمودان شاشة واحدة + Bottom Sheet · **الجداول كروت رأسيّة بلا تمرير أفقيّ** · الفلاتر زرّ واحد · الفعل الرئيسيّ في `@section('mobile_action')` · لمسة 44×44.
- **الألوان (2.16):** استخدم `<x-state-badge state="ok|warn|danger|idle|honor" />` — **وممنوع** استعمال التركوازيّ كحالة، و**ممنوع** اللون بلا رمز.
- **الأيقونات:** SVG بهويّة المنصّة — **ممنوع أيّ مكتبة أيقونات جاهزة**.
- **الإحساس (2.17):** ردّ فوريّ لكلّ فعل · «اتحفظ ✓» مع الحفظ التلقائيّ · رسالة الخطأ = ماذا حدث + ماذا تفعل · الحالات الفارغة تشجّع ولا تعاتب · **العدّاد التصاعديّ يعرض الرقم النهائيّ في كلّ الأحوال**.

## 5) اللغة
- كلّ نصوص الواجهة **عربيّة**، بنبرة واحدة: مبسّطة محترمة دافئة — بلا مبالغة وبلا جفاف.
- التعليقات في الكود عربيّة، وتشرح **لماذا** لا **ماذا**، مع الإحالة لبند الدستور: `// حدّ الخسارة اليوميّ (13.4-ن-و)`.

## 6) الجودة
- **اختبار Feature واحد على الأقلّ لكلّ شاشة رئيسيّة** في `tests/Feature/<Area>/`.
- `./vendor/bin/pint` قبل التسليم.
- `php artisan test` لازم يعدّي **بالكامل** — لو كسرت اختبار غيرك، صلّحه أو بلّغ.
- **ممنوع** `dd()` أو `dump()` أو كود معلَّق أو TODO بلا تنفيذ.

## 6.1) وثيقة التقدّم داخل كلّ مجلّد (2.12) — قاعدة رئيسيّة
كلّ مجلّد فيه `_STATUS.md`: الغرض · المُنجَز · **المتبقّي** · **الجاري الآن** · التبعيّات · آخر تحديث.
```bash
php artisan docs:status          # ولّد/حدّث الجرد من الكود نفسه
php artisan docs:status --check  # يخرج بكود 1 لو مجلّدٌ بلا وثيقة أو جردُها قديم
```
- الأقسام بين `تلقائيّ:بداية` و`تلقائيّ:نهاية` **يكتبها الأمر** — لا تحرّرها بيدك.
- **«المتبقّي» و«الجاري الآن» بيدك أنت** ولا يمسّهما الأمر: حدّثهما **قبل الجلسة وبعدها**.
- أنشأت مجلّدًا جديدًا؟ شغّل `docs:status` قبل التسليم — الاختبار يسقط بدونها.
