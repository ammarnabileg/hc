# المنصّة — منصّة تعليم عربيّة بطبقة تطوّع

> **المرجع الحاكم للسلوك والقواعد هو `دستور اساسي.md`** في جذر الريبو.
> أيّ تعارض بين الكود والدستور ⟵ **الدستور هو الصواب**.
> وقواعد الكتابة في `docs/BUILD.md`.

## التنصيب لأوّل مرّة (2.2)

بعد رفع الملفّات وتشغيل `composer install`، افتح `‏/setup.php` في المتصفّح:
سبع شاشات (توكن ⟵ فحص المتطلّبات ⟵ قاعدة البيانات باختبار اتّصال قبل الحفظ ⟵
تجهيز الجداول ⟵ بيانات المنصّة ⟵ حساب المالك ⟵ الإنهاء). وبعد الإنهاء
**تُقفَل صفحات التنصيب كلّها وتردّ 404**.

التوكن في `storage/setup-token.txt`، ولا يُعرَض على الشاشة إلّا في وضع التطوير.

## التشغيل (للمطوّر)

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate

php artisan migrate --seed               # الصلاحيّات والأدوار والعملات والبوزشنز وقيم Rep والإعدادات
php artisan db:seed --class=DemoSeeder   # بيانات تجريبيّة عربيّة (للتطوير فقط — لا تُرفَع للإنتاج)

npm run build
php artisan serve
```

**الجدولة** (لازمة لمحرّك التصعيد وتصفير Rep والبنود المتكرّرة):

```
* * * * * cd /path && php artisan schedule:run >> /dev/null 2>&1
```

## البنية

| المجلّد | ما فيه |
|---|---|
| `app/Support/Access/` | **محرّك الصلاحيّات** (12.2.1): النطاقات الستّة · Deny > Allow · منع تصعيد الامتياز · عزل الحسّاس |
| `app/Services/<المجال>/` | منطق كلّ مجال — والقرارات الماليّة والتلعيبيّة **في الخادم حصرًا** |
| `routes/parts/` | ملفّ مسارات لكلّ مجال، يُحمَّل تلقائيًّا من `routes/web.php` |
| `database/data/permissions.json` | **مصفوفة الصلاحيّات** (1006 صلاحيّة على 215 موردًا) |
| `resources/views/components/` | مكوّنات مشتركة — لا تُعاد كتابتها داخل المجالات |

## قواعد لا يجوز كسرها

- **لا رقم ولا نصّ محروق:** كلّ قيمة من `setting()`، وقيم درجة الالتزام من `rep_rule()` (2.13).
- **الصلاحيّة على كلّ مسار**، والعنصر المحظور **يُخفى لا يُعطَّل** (2.15).
- **اللون لا يحمل المعنى وحده** — استعمل `<x-state-badge>` دائمًا (2.16).
- **الماليّات ومفاتيح البوّابة لمالك المنصّة وحده** — 27 صلاحيّة في المجموعة المحميّة.
- **الرصيد يُضاف من الويب هوك حصرًا** ومنع التكرار على `invoice_id` (19.5-ج-2).
- **لا مكتبات واجهة خارجيّة:** الرسوم والأيقونات وQR والكانفاس كلّها SVG/GD مكتوبة داخل المشروع.
- **الحروب محصّلة صفريّة:** ما يكسبه فائز يخسره خاسر — **ممنوع سكّ تذاكر أو XP من العدم** (15.2-6).
- **XP مصدره واحد:** كلّ منحٍ يمرّ بـ`EconomyLedger` فيكتب في دفتر الأستاذ والمحفظة و`users.xp` معًا.
- **لا تتبّع بلا موافقة:** `Ads\Consent` هو الحارس، ويُنادى في مسار المتصفّح ومسار الخادم كليهما (21.3-د).

## الاختبارات والفحوص

```bash
php artisan test              # 1086 اختبارًا
php artisan settings:coverage # يفشل لو ظهرت مجموعة إعدادات بلا شاشة (2.13)
php artisan settings:hardcoded # يفشل لو زاد نصٌّ عربيّ محروق على العتبة (2.13-أ/ب)
./vendor/bin/pint             # تنسيق
```

> `settings:coverage` يقيس **المفاتيح**، و`settings:hardcoded` يقيس **النصّ الذي
> لا يمرّ بمفتاح أصلًا** — فلا يُقرَأ أحدهما وحده على أنّه امتثالٌ لـ2.13.
> وكلاهما يعلن **ما لا يقيسه** في مخرجاته؛ اقرأه قبل أن تقرأ الرقم.

## متطلّبات الإنتاج

- **Imagick** — للقارئ المحميّ (يعمل بـGD ببديل آمن، لكن بجودة أقلّ).
- **خطّ Cairo** في `public/fonts/Cairo-Regular.ttf` — **مرفوع في الريبو**، ولازم لمولّد الشهادات وصور الاستوديو وPDF الـATS. وبدونه يتحوّل مسار الـATS للنسخة القابلة للطباعة برسالة تشرح السبب.
- **مفاتيح بوّابة فواتيرك** تُضبَط من لوحة الإدارة (لا تُكتب في الكود ولا في `.env`).
- **`schedule:run` كلّ دقيقة** — بدونه تتوقّف: نوافذ التصعيد · تصفير Rep الشهريّ · سلّم الخمول · النسخة الاحتياطيّة المجدولة · التقارير المجدولة.
- **الطبقة الأماميّة** يُفضَّل أن تمرّر ترويسة دولة (مثل `CF-IPCountry`) — تُستعمل لتحديد توقيت المستخدم في الإتاحة الزمنيّة ونادي الخامسة، ومعها بديل من المتصفّح يتحقّق منه الخادم.
